# 机械加工厂内部自动报价系统

基于 Streamlit 的内部报价工具，适用于铸铁、球铁、铸铝件及 CNC 加工和表面处理报价。

## 功能

- 录入客户、产品、数量、材料、重量、CNC 工时、表面处理及包装费用。
- 自动计算材料、CNC、表面处理、包装、总成本及最终报价。
- 在“成本参数设置”中修改公司名、利润系数、材料/工艺/CNC 单价；参数保存于 `pricing_config.json`，不写死在代码中。
- 将报价保存在本地 SQLite 数据库 `quotes.db`，支持历史查询。
- 一键导出包含产品信息、成本明细和最终报价的 Excel 报价单。

## 运行方法（Windows）

1. 安装 Python 3.10 或更高版本。
2. 在本项目文件夹打开终端，安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

3. 启动应用：

   ```powershell
   streamlit run app.py
   ```

4. 浏览器会自动打开；如未自动打开，请访问终端显示的本地地址（通常为 `http://localhost:8501`）。

## 数据说明

- `pricing_config.json`：首次启动时自动创建，存储可维护的成本参数。
- `quotes.db`：自动创建，存储本机报价历史。请定期备份此文件。
- 本版的重量、工时、包装费用和最终报价均按“当前产品整批”录入及计算。

## 后续扩展建议

可在现有参数配置中增加材料、工艺，以及后续接入 PDF/STEP 文件解析和 AI 辅助报价模块。
