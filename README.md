# 机械加工自动报价系统

面向铸造与机加工厂的 Streamlit 内部报价工具。自动识别结果只作为工程师复核起点，所有设备和工时均可修改、删除或新增后再进入报价。

## 核心报价逻辑

- 所有重量、工时、表面处理和包装默认按**单件**输入。
- 单件成本 = 铸件 + 已确认设备工时 + 人工 + 单件热处理/检测/表面处理/包装。
- 整批成本 = 单件重复成本 × 数量 + 整批一次性费用；整批报价再按报价模式计算。
- 单件成本、单件报价是整批成本/报价按数量分摊后的参考值，因此 `单件报价 × 数量 = 整批报价`，不会重复加一次性费用。
- 编程、夹具、模具、首件检测、运输等可设置为整批一次性费用，只计算一次。

### 工序时间与攻牙

- 每个工序可设为 **每件**、**每批一次**、**每对产品** 或 **手动总价**。每对工序按 `ceil(数量÷2)` 计算；数量为奇数会提示最后一件无法成对交付。
- 首件夹具安装、首次找正、编程和试切属于每批一次；上料、下料和重复夹紧属于每件重复时间。
- 图纸识别出的每一种螺纹组均须由工程师选择：无螺纹加工、设备刚性攻牙、人工攻牙或混合攻牙。未确认的螺纹不会悄悄带入报价。
- 报价页和 Excel 同时列出单件时间、每批时间、整批总时间、设备/人工单价和整批金额。

### 打样、批量与阶梯报价

- **打样单价**：按“打样数量”分摊编程、首件找正、试切、夹具首次安装和首件检测等一次性费用。
- **批量平均单件成本**：按本次批量数量分摊整批一次性费用。
- **批量单价**：批量平均单件成本按所选报价模式计算后的单价；批量单价 × 批量数量 = 整批报价。
- 阶梯报价可维护数量和批量效率系数。效率系数默认只作用于上下料、夹紧、换刀、测量、倒角、去毛刺等重复辅助动作，不降低材料、纯切削、钻孔或攻牙。
- 人工攻牙显示为“人工工位”，底孔钻削仍单独保留为设备工序；混合攻牙拆分显示设备攻牙和人工攻牙两行。

### 批量加工费折扣

- 批量折扣在“成本参数设置”中按数量区间维护，默认从 1 件的 100% 到 100 件以上的 85%。
- 折扣仅作用于每件重复的设备加工费、人工攻牙费和其他加工人工费，用于客户报价。
- 折扣不改变实际设备工时、人工工时、生产周期或设备负荷；材料、表面处理、热处理、包装、运输和全部整批一次性费用也不参与折扣。
- 工序确认后，系统只读取 `confirmed_operations` 作为报价数据源。修改确认表会使旧报价失效，必须再次确认后计算。

### 两种模式

1. **成本加利润**：材料成本价 + 工时成本 + 其他成本，最后乘利润系数。
2. **直接销售单价**：铸件销售单价 + 直接设备报价 + 表面处理报价；不重复乘利润系数。

## 图纸与模型

- PDF：优先文字提取；文字不足时尝试 OCR（部署环境需安装 Tesseract）。
- 标题栏：识别中文/英文公司名称、产品名称、图纸号和零件号；若 CAD 字体文字提取乱码，会自动尝试 OCR，并在 Excel 中保留识别来源与置信度。
- 孔特征表：支持“标签—规格—数量”跨行孔表。底孔、沉孔/沉头和攻牙会继承同一标签数量，不会把视图标签重复累加。
- 大型精密板件：当尺寸、孔表数量和精磨/高精度信号同时满足条件时，系统会分出龙门正反面、侧向转序、孔系刚性攻牙和精磨工序；结果仍须由工程师确认。
- DXF：读取 TEXT/MTEXT/ATTRIB 文字。
- STEP：计算净重、毛坯计价重量、实际平面面积、同轴圆柱组；不再用总面数或圆柱面数量直接乘固定工时。
- DWG、X_T 不在网页端提供上传，因为不能可靠解析几何或文字。

## 设备识别原则

- 车床：需同时具备 2D 的大螺纹/密封槽/同轴孔等强信号，或 STEP 大面积同轴回转组。局部孔壁不触发车床。
- CNC：零件在普通加工中心行程与承重范围内时默认使用。
- 卧加：箱体、多侧孔/镗孔、位置度/同轴度要求且减少翻面有优势时推荐。
- 龙门：超过普通 CNC 能力，或大型机架/床身、多侧面大平面时推荐。
- 磨床：明确磨削/配磨、两件等高≤0.01、Ra≤0.8 或中小关键大平面 0.01 级精度时推荐。配对磨显示每对时间与单件分摊；大件超出普通磨床能力时仅提示人工确认。

## 使用方法

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

1. 上传 PDF/DXF，再上传 STEP。
2. 在“自动识别结果确认表”中确认、修改、删除或新增工序。
3. 选择报价模式、表面处理、其他成本和包装方式。
4. 查看单件/整批成本与报价，保存历史记录或导出 Excel。
5. 在历史报价页回填实际设备工时，供同类产品校准参考；系统不会覆盖原始公式估算。
